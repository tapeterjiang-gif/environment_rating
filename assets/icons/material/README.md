# Material environment icons

These SVG files are the 24 px default-weight, unfilled **Material Symbols Rounded** assets from Google’s [`material-design-icons`](https://github.com/google/material-design-icons) repository.

| Environment parameter | Material Symbol | File |
| --- | --- | --- |
| Temperature | `device_thermostat` | `device_thermostat.svg` |
| Relative humidity | `humidity_percentage` | `humidity_percentage.svg` |
| CO₂ | `co2` | `co2.svg` |
| PM2.5 / PM10 | `blur_on` | `blur_on.svg` |
| Formaldehyde | `science` | `science.svg` |
| TVOC index | `speed` | `speed.svg` |
| Noise | `graphic_eq` | `graphic_eq.svg` |
| Illuminance | `light_mode` | `light_mode.svg` |

The assets are licensed under Apache License 2.0; see [`LICENSE`](LICENSE). Android Vector Drawables in `android/environment-rating/src/main/res/drawable` are generated from these SVG paths.
