# Material environment icons

These SVG files use Google **Material Symbols Rounded** at weight 400, unfilled. The five outdoor icons were copied from the Apache-2.0 [`@material-symbols/svg-400` rounded SVG package](https://github.com/marella/material-symbols/tree/main/svg/400) (version 0.49.0), which packages Google's symbols; their display size was set to 24 px without changing the paths.

| Environment parameter | Material Symbol | File |
| --- | --- | --- |
| Temperature | `device_thermostat` | `device_thermostat.svg` |
| Relative humidity | `humidity_percentage` | `humidity_percentage.svg` |
| CO₂ | `air` | `air.svg` |
| PM2.5 / PM10 | `blur_on` | `blur_on.svg` |
| Formaldehyde | `science` | `science.svg` |
| TVOC index | `speed` | `speed.svg` |
| Noise | `graphic_eq` | `graphic_eq.svg` |
| Illuminance | `light_mode` | `light_mode.svg` |
| Outdoor O₃ | `dehaze` | `dehaze.svg` |
| Outdoor CO | `detector_smoke` | `detector_smoke.svg` |
| Outdoor SO₂ | `foggy` | `foggy.svg` |
| Pollen | `local_florist` | `local_florist.svg` |
| UV Index | `flare` | `flare.svg` |
